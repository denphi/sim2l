# FileManager Guide

## Overview

The `FileManager` provides a clean interface for managing files generated by sim2l runs. It integrates with the run database to retrieve execution outputs and provides tools for organizing, exporting, and tracking simulation files.

## Quick Start

### Basic Usage

```python
from sim2l.database import FileManager

# Initialize FileManager
fm = FileManager()

# Get all files from a specific run
files = fm.get_run_files("exec-2024-001")

# Export a file to filesystem
fm.export_run_file(
    "exec-2024-001",
    "output.dat",
    "/tmp/output.dat"
)
```

### With Remote Cache Service

```python
from sim2l.database import FileManager, get_session_manager

# Create session
session = get_session_manager().create_anonymous_session()

# Initialize with cache service
fm = FileManager(
    cache_url="http://localhost:8001",
    session_id=session.session_id
)

# Now all file metadata is stored in distributed cache
files = fm.get_simulation_files("thermal_sim", "1.0.0")
```

## Core Features

### 1. Get Files from a Run

Retrieve all files generated by a specific sim2l execution:

```python
fm = FileManager()

# Get all files from an execution
files = fm.get_run_files("exec-2024-001")

for file in files:
    print(f"{file['name']}: {file['size']} bytes")
    print(f"  Category: {file['category']}")
    print(f"  Content-Type: {file['content_type']}")
```

**File Information Includes**:
- `id` - Unique identifier
- `name` - File name
- `execution_id` - Which run generated it
- `category` - File category (output, log, artifact, etc.)
- `content_type` - MIME type
- `size` - File size in bytes
- `uri` - File path/URI
- `date_created` - Creation timestamp
- `metadata` - Additional metadata

### 2. Export Files to Filesystem

Export files from the run database to your local filesystem:

```python
fm = FileManager()

# Export a single file
success = fm.export_run_file(
    execution_id="exec-2024-001",
    file_name="output.dat",
    output_path="/tmp/output.dat"
)

# Batch export all files
import os
files = fm.get_run_files("exec-2024-001")
output_dir = "/tmp/exports"
os.makedirs(output_dir, exist_ok=True)

for file in files:
    output_path = os.path.join(output_dir, file['name'])
    fm.export_run_file("exec-2024-001", file['name'], output_path)
```

### 3. Get All Files for a Simulation

Retrieve files across all runs of a simulation:

```python
# Requires catalog service running
session = get_session_manager().create_anonymous_session()
fm = FileManager(
    cache_url="http://localhost:8001",
    session_id=session.session_id
)

# Get all files for a simulation
files = fm.get_simulation_files(
    simulation_name="thermal_sim",
    simulation_version="1.0.0"
)

# Or get files from a specific execution
files = fm.get_simulation_files(
    simulation_name="thermal_sim",
    execution_id="exec-2024-001"
)
```

### 4. Organize Files in Folders

Create folder hierarchies for organizing files:

```python
fm = FileManager()

# Create a folder
folder = fm.create_folder(
    name="simulation_outputs",
    creator="user123"
)

# Create a file in the folder
file = fm.create_file(
    name="result.csv",
    size=2048,
    uri="/data/result.csv",
    creator="user123",
    parent_id=folder['id']
)

# List folder contents
contents = fm.list_folder(folder['id'])
for item in contents:
    print(item['name'])
```

### 5. File Operations

Standard file management operations:

```python
fm = FileManager()

# Create file
file = fm.create_file(
    name="output.dat",
    size=1024,
    uri="/path/to/file",
    creator="user123",
    metadata={'custom': 'data'}
)

# Get file
file = fm.get_file(file['id'])

# Update file
fm.update_file(file['id'], size=2048, status=True)

# Move file to different folder
fm.move_file(file['id'], new_parent_id=folder['id'])

# Delete file
fm.delete_file(file['id'])

# Delete folder and all contents
fm.delete_file(folder['id'], recursive=True)
```

## Common Workflows

### Workflow 1: Post-Simulation File Processing

```python
from sim2l.database import FileManager

def process_simulation_outputs(execution_id):
    fm = FileManager()

    # Get all output files
    files = fm.get_run_files(execution_id)

    # Filter for specific file types
    csv_files = [f for f in files if f['name'].endswith('.csv')]
    log_files = [f for f in files if f['category'] == 'log']

    # Export CSV files for analysis
    import os
    export_dir = f"/data/analysis/{execution_id}"
    os.makedirs(export_dir, exist_ok=True)

    for csv in csv_files:
        output_path = os.path.join(export_dir, csv['name'])
        fm.export_run_file(execution_id, csv['name'], output_path)

    return export_dir

# Use after running simulation

# export_dir = process_simulation_outputs(result.execution_id)
```

### Workflow 2: Organize Simulation Runs

```python
from sim2l.database import FileManager

def organize_simulation_runs(simulation_name, version):
    session = get_session_manager().create_anonymous_session()
    fm = FileManager(
        cache_url="http://localhost:8001",
        session_id=session.session_id
    )

    # Create main folder for simulation
    main_folder = fm.create_folder(
        name=f"{simulation_name}_v{version}",
        creator="system",
        metadata={
            'simulation': simulation_name,
            'version': version
        }
    )

    # Get all files for this simulation
    files = fm.get_simulation_files(simulation_name, version)

    # Group by execution
    executions = {}
    for file in files:
        exec_id = file['execution_id']
        if exec_id not in executions:
            executions[exec_id] = []
        executions[exec_id].append(file)

    # Create subfolder for each execution
    for exec_id, exec_files in executions.items():
        exec_folder = fm.create_folder(
            name=f"run_{exec_id}",
            creator="system",
            parent_id=main_folder['id'],
            metadata={'execution_id': exec_id}
        )

        # Register files in execution folder
        for file in exec_files:
            fm.create_file(
                name=file['name'],
                size=file['size'],
                uri=file['uri'],
                creator="system",
                parent_id=exec_folder['id'],
                metadata=file['metadata']
            )

    return main_folder['id']
```

### Workflow 3: File Comparison Across Runs

```python
from sim2l.database import FileManager

def compare_run_outputs(exec_id_1, exec_id_2, file_name):
    fm = FileManager()

    # Export files from both runs
    import tempfile
    with tempfile.TemporaryDirectory() as tmpdir:
        path1 = f"{tmpdir}/run1_{file_name}"
        path2 = f"{tmpdir}/run2_{file_name}"

        fm.export_run_file(exec_id_1, file_name, path1)
        fm.export_run_file(exec_id_2, file_name, path2)

        # Compare files (example with CSV)
        import pandas as pd
        df1 = pd.read_csv(path1)
        df2 = pd.read_csv(path2)

        # Calculate differences
        diff = df1.compare(df2)
        return diff
```

## Integration with Run Database

The FileManager integrates directly with the run database:

```python
from sim2l.database import RunDatabase, FileManager

# Direct access to run database
run_db = RunDatabase("exec-2024-001")

# Get artifacts (files) from run database
artifacts = run_db.get_artifacts()

# FileManager provides a higher-level interface
fm = FileManager()
files = fm.get_run_files("exec-2024-001")

# Both return file information, but FileManager adds:
# - File organization (folders)
# - Export capabilities
# - Integration with cache service
# - Consistent file metadata format
```

## Deployment Modes

### Local Mode (Default)

```python
# No services required
fm = FileManager()

# Files stored in local cache
files = fm.get_run_files("exec-001")
```

**Features**:
- No network dependencies
- Fast local access
- Good for single-user development

**Limitations**:
- Not shared across users
- Limited search capabilities

### Remote Mode (Cache Service)

```python
# Requires cache service running
session = get_session_manager().create_anonymous_session()
fm = FileManager(
    cache_url="http://localhost:8001",
    session_id=session.session_id
)

# File metadata stored in distributed cache
files = fm.get_simulation_files("thermal_sim")
```

**Features**:
- Shared across users
- Persistent storage
- Better search capabilities (when integrated with catalog)

**Requirements**:
- Cache service running (port 8001)
- Valid session ID

## API Reference

### FileManager Class

#### Constructor

```python
FileManager(
    cache_url: Optional[str] = None,
    session_id: Optional[str] = None,
    simulation_name: str = "file_manager",
    simulation_version: str = "1.0.0"
)
```

**Parameters**:
- `cache_url` - URL of cache service (None = local mode)
- `session_id` - Session ID for authentication
- `simulation_name` - Name for cache entries
- `simulation_version` - Version for cache entries

#### Methods

**File Retrieval**:
```python
get_run_files(execution_id: str) -> List[Dict[str, Any]]
get_simulation_files(
    simulation_name: str,
    simulation_version: Optional[str] = None,
    execution_id: Optional[str] = None
) -> List[Dict[str, Any]]
get_file(file_id: str, expand_children: bool = False) -> Optional[Dict[str, Any]]
```

**File Export**:
```python
export_run_file(
    execution_id: str,
    file_name: str,
    output_path: str
) -> bool
```

**File Operations**:
```python
create_file(
    name: str,
    size: int,
    uri: str,
    creator: str,
    parent_id: Optional[str] = None,
    **kwargs
) -> Dict[str, Any]

update_file(file_id: str, **updates) -> bool
delete_file(file_id: str, recursive: bool = False) -> bool
move_file(file_id: str, new_parent_id: str) -> bool
```

**Folder Operations**:
```python
create_folder(
    name: str,
    creator: str,
    parent_id: Optional[str] = None,
    **kwargs
) -> Dict[str, Any]

list_folder(folder_id: str) -> List[Dict[str, Any]]
```

## Best Practices

### 1. Use Context Managers

```python
with FileManager() as fm:
    files = fm.get_run_files("exec-001")
    # Automatic cleanup
```

### 2. Handle Missing Files Gracefully

```python
files = fm.get_run_files("exec-001")
if not files:
    print("No files found for this execution")
else:
    # Process files
    pass
```

### 3. Organize by Simulation and Version

```python
# Create clear folder hierarchy
main_folder = fm.create_folder(
    name=f"{sim_name}_v{version}",
    metadata={'simulation': sim_name, 'version': version}
)

# Group runs in dated subfolders
from datetime import datetime
date_folder = fm.create_folder(
    name=datetime.now().strftime("%Y-%m-%d"),
    parent_id=main_folder['id']
)
```

### 4. Export Only What You Need

```python
# Filter before exporting
files = fm.get_run_files("exec-001")
output_files = [f for f in files if f['category'] == 'output']

for file in output_files:
    fm.export_run_file("exec-001", file['name'], f"/data/{file['name']}")
```

---

## Limitations

1. **Search Functionality**: Basic search is limited. For advanced search, use the catalog service.

2. **Cache-Based Storage**: File metadata stored in cache may not support complex queries.

3. **File Content**: FileManager stores metadata only. Actual file content is in run databases.

4. **Root Folder**: Listing root folder ('0') is not fully supported in cache mode.

## Troubleshooting

### Issue: Files not found

```python
files = fm.get_run_files("exec-001")
if not files:
    # Check if run database exists
    from sim2l.database import RunDatabase
    try:
        run_db = RunDatabase("exec-001")
        print("Run database exists")
    except Exception as e:
        print(f"Run database error: {e}")
```

### Issue: Export fails

```python
import os

success = fm.export_run_file("exec-001", "output.dat", "/tmp/output.dat")
if not success:
    # Check if file exists in run
    files = fm.get_run_files("exec-001")
    file_names = [f['name'] for f in files]
    print(f"Available files: {file_names}")

    # Check if output directory is writable
    output_dir = os.path.dirname("/tmp/output.dat")
    print(f"Directory writable: {os.access(output_dir, os.W_OK)}")
```
